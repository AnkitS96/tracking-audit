Tracking Audit

Paste or upload tracking data and get a plain English list of what is wrong. Runs in your browser; nothing is uploaded anywhere.

Export from Tag Manager: Admin, Export Container, then paste the JSON. Finds events sent twice, tags that never fire, and pixels initialised twice (Meta, TikTok, Snapchat, LinkedIn).

A JSON list of events with platform, event_name, source ("browser" or "server"), event_id, value and currency. Checks deduplication, event names, and purchase values.

The JSON body you send to the Conversions API ({"data":[...]}). Checks event time, action source, event_id, hashing, IP and user agent, cookies, test_event_code and purchase fields. Use made up data only: it contains personal data fields.

Do the product ids in your events exist in your catalog? Paste events (a list, or a Conversions API body) first, then the catalog CSV. Catches wrong ids, upper and lower case, product id versus variant id, and price differences.

A product feed as CSV with a header row. Meta rules are the most complete; TikTok and Snapchat are starter rules.

Sample data is made up. The rules are starter rules: check them against each platform's current documentation before relying on them. Built by Ankit Singh.
